## The work cards

`work-lume`, `work-nest`, `work-tempo`, `work-piggy-wallet`, `work-noted`

One per case study - five in total. The open-source utilities no longer get
cards (they sit behind the "More on GitHub" link), so they need no images.

Cards crop to 4:3 and darken slightly at rest; on hover the image is replaced
by the vermilion flood, so **the image only ever reads at rest** - pick shots
that are legible small and don't depend on fine detail.
