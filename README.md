# Fernando Halim - Personal Portfolio

A personal portfolio website built to showcase projects, skills, and professional experience. 

## Tech Stack

- **Next.js 16**
- **React 19**
- **Tailwind CSS v4**
- **Framer Motion**
- **TypeScript**

## Local Development

To run the project locally, run the following commands in your terminal:

```bash
# clone the repository
git clone <repository-url>

# navigate into the directory
cd client-porto

# install dependencies
npm install

# start the development server
npm run dev
